# 🧮 Next.js Calculator

A functional, responsive calculator built to master **Next.js** and **React**. This project focuses on handling complex logic for mathematical operations while maintaining a clean user interface.

[**Live Demo via Vercel**](calculator-murex-psi.vercel.app)

## 🚀 Features
- **Next.js Framework:** Leverages modern React patterns for optimal performance.
- **Responsive Design:** Fully functional on mobile and desktop devices.

## 🛠️ Tech Stack
- **Framework:** Next.js
- **Logic:** JavaScript (ES6+)
- **Styling:** CSS Modules
- **Deployment:** Vercel

## 📖 What I Learned
During this project, I deepened my understanding of the React component lifecycle and the nuances of handling string-to-number conversions in JavaScript.
